# 🍅 Tomato – Food Delivery Website

A full-stack food delivery website built using React, Node.js, Express, and MongoDB.

## 🚀 Live Demo

### Customer Website
https://tomato-website-oiop.onrender.com

### Backend API
https://tomato-backend-dgur.onrender.com

## ✨ Features
- Customer authentication
- Food browsing
- Search
- Cart
- Online ordering
- Order history
- Admin dashboard
- Food management
- Order management
- Customer management
- Analytics

## 🛠️ Tech Stack
- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Render
