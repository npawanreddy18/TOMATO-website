# Tomato – Food Delivery Website.

A full-stack food delivery web application built with React, Node.js, Express, and MongoDB.

## 🚀 Live Demo

### Customer Website
https://tomato-website-oiop.onrender.com

### Admin Panel
https://tomato-admin-olzf.onrender.com

### Backend API
https://tomato-backend-dgur.onrender.com

## ✨ Features

- Customer authentication
- Food browsing
- Search
- Cart management
- Online ordering
- Order history
- Admin dashboard
- Food management
- Order management
- Customer management
- Analytics

## 🛠️ Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Render
